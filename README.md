A tiny Python program that writes one short poem about agency — the power to stop and to stay — to `entry.txt`. The poem is fixed and validated in code (1–280 Unicode code points, UTF-8, LF endings), so every run produces byte-identical output with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
